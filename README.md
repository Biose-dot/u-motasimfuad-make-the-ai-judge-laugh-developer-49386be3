[Make the AI Judge Laugh: Developer Excuses](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3).

One funny single-line excuse a developer gives when code breaks in production, under 200 characters. It worked on my machine — production is the evil twin.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> It worked on my machine — production is just my machine's evil twin that never got the update, the config, or the memo.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
